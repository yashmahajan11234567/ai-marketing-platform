# AI Marketing Platform — Pitch Website

AI Marketing & WhatsApp Automation Platform for Local Businesses

A professional, interactive pitch deck — 10 slides covering the problem, solution, market, pricing, and business model.

## Deploy on Vercel

**One-click deploy:**
https://vercel.com/new/clone?repository-url=https://github.com/yashmahajan11234567/ai-marketing-platform

Or go to https://vercel.com → Add New → Project → Import the repo above.

## Local Development

```bash
git clone https://github.com/yashmahajan11234567/ai-marketing-platform.git
cd ai-marketing-platform
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
```

## Tech Stack

- **Next.js 15** (App Router, SSR)
- **React 19**
- **Tailwind CSS v4**
- **TypeScript**
- **Inter + JetBrains Mono** fonts
